# ajio_scrapping

Overview

This project is a Python-based web scraper designed to extract product information from the AJIO e-commerce platform. It automates the collection of product data, making it useful for data analysis, price monitoring, market research, and machine learning projects.

The scraper navigates through AJIO product listings, collects relevant product details, and stores the extracted data in a structured format for further analysis.

Features
Scrapes product information from AJIO.
Extracts product name, brand, price, discount, ratings, and product URL.
Supports scraping multiple product categories.
Handles pagination to collect data from multiple pages.
Saves data in CSV format for easy analysis.
Modular and reusable code structure.
Error handling for failed requests and missing data.
